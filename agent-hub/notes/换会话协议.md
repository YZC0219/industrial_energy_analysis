# 换会话协议

> 来源：luanyujia-workbench 记忆机制事故清单 · 适配本机文件工作区（无 Electron 壳）。
> 成立判据：**新会话只读交接，30 秒内能说出「下一步干什么」**。

## 什么时候换

| 触发 | 换吗 |
|---|---|
| 宿主说「换会话」 | ✅ |
| 上下文真死局（如 413，且压缩后仍挂） | ✅ |
| 只是到压缩线、还没报错 | ❌ 先干完手上的 |
| 任务做完、话题结束 | ✅ 建议换 |

## 四步（不许跳）

1. **写交接**
   覆盖写该场景 `场景私有记忆.md` 的 §〇（五小节齐全），并同步 `HANDOVER.md` 三行指针。
   写不出「下一步」→ **不许换**（这轮还没结案）。

2. **换**
   旧会话归档（改名/移入 `archive/` 或场景 `归档/`）；开新会话。

3. **更新指针**
   凡是钉住旧会话 id / 标题 / 路径的地方，改成新会话；`HANDOVER.md` 署名改成新会话 + 日期。

4. **自检**
   新会话只读 `HANDOVER.md` + §〇，口头（或一行回复）说出：我是谁 / 干到哪 / 下一步 / 卡点。
   说不全 = 交接失败，回到步骤 1，不继续派活。

## 减肥（§〇 或主文件超红线时）

1. 先快照（拷一份「搬之前」）
2. 历史搬进 `归档/`，主文件只留入口 + 指针
3. 核对：搬前非历史行 == 搬后非历史行（0 差异才算没丢）
4. 索引/台账体检：死链、未登记、过期

无脚本时：人工 diff 快照与搬后文件，并在 §〇「私有记忆变更」记一行「已减肥 + 快照路径」。

## 与派单的关系

- 换会话 ≠ 取消未回执派单。看板里「未回执」必须先销账或显式移交，再换。
- 派单要动手：真投递；只是知道：公告且不要求回。回执 = 结论 + 证据 + 落盘路径；同事一事 ≤3 条，末行 `【结束】`。
