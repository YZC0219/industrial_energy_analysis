# 场景模板（拷贝即用）

```text
复制本目录 → scenes\<场景名>\
改 AGENTS.md 里的「核心职责」与边界
把 §〇 写成当前真进度（覆盖写，不追加）
```

| 文件 | 谁写 | 作用 |
|---|---|---|
| `AGENTS.md` | 人 | 定位卡：是干什么的、边界在哪 |
| `场景私有记忆.md` | 人 | §〇 交接 + 核心职责 + 资产地图 |
| `HANDOVER.md` | 人/工具 | 换会话时的入口指针（可与 §〇 同步） |
| `身份卡.md` / `场景画像.md` | 有工具才生成 | 手改即校验失败；无工具时先不建 |

开新场景后，立刻用 `notes/换会话协议.md` 跑一遍「写交接 → 换 → 接上」。
