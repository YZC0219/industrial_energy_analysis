## 统一口径

`governance/analysis_formulas.yaml` 升为版本 2，在月环比、七日历日均值和费用帕累托之外，增加三个经过校验的定义。Python 参考计算与浏览器解释器使用相同契约；未知操作或未经支持的策略变更会停止生成报告。

| 定义 | 规则 | 边界 |
| --- | --- | --- |
| 固定基线离散度 | CV = σ / μ × 100%；上界 μ + 2σ，下界 max(0, μ − 2σ) | μ 为零时 CV 为空；沿用 Q24 固定均值、标准差及 SQL 异常标记 |
| 历史单耗基线差额 | 2025 产量 × (2024 单耗 − 2025 单耗) / 1000 | 在同一车间、同一产量单位内计算；kgce 转 tce；负值保留 |
| 基线差额折算 | 差额 tce × Q01 全期碳排或费用 / Q01 全期能耗 | 读取原始全期合计，不从舍入后的折碳或折费用总额反推系数；能耗为零时折算为空 |

CV 表示相对离散程度，不能解释成“CV 越大就越容易顶破 2σ”。对于相同绝对偏差，σ 越大，`Z = (x − μ) / σ` 的绝对值越小。报告已修正这段说明，但没有重新计算或替换历史 SQL 的异常日、Z 值、残差基线和 CUSUM 结果。

报告的费用系数现在随 Q01 数据计算并显示，去除了固定的 ¥3,378/tce 文案。分项表、合计、卡片和鼠标提示均从同一全期口径折算，即使正负差额相抵、合计为零，分项折算仍能保留。负差额图形位于零轴左侧，零差额条形宽度为零；没有有效分母时显示“—”。

基线差额仍使用已有 Q08 导出单耗与 Q07 年度产量；单耗本身已有导出精度，分项差额保留一位小数后汇总。这不是新增实测数据，也不是提高原始计量精度。报告将该部分改为“历史单耗基线差额”和“折算估算”，明确没有验证某项措施的因果效果或净收益。原有阶段五情景入口保持不变，不重复构建其分析流程。
