# 报告版本归档与回退

2026-10-08，本窗口在九项报告公式之后补齐版本交付机制。已只读核对其他窗口的工作，未重复处理在线模型、诊断服务、CDC 调度或全库 bug 回归。

实现位于 `governance/report_delivery.py` 和 `tools/report_delivery.py`。默认目录为 `D:\industrial_energy_analysis\output\extensions\report_delivery`，每个版本使用独立目录；`build` 仅准备版本，不自动切换当前版本。

## 版本包含什么

- 从已通过本机语义导出的目录读取 Q01～Q29，并冻结输入字节；本次包含 29 份分析 CSV 和原始能源 CSV，共 30 个输入文件。
- 冻结可用的清洗台账、预测/数仓验证等报告依赖；缺失的可选依赖保持缺失，不用其他批次的数据补齐。
- 在冻结目录中通过原有校验读取器生成 HTML，保存嵌入的数据、九项公式契约和源记录。
- 留存每个文件的 SHA-256、源码摘要、来源目录和创建时间。没有复制 `.env`、数据库口令或诊断反馈数据库。

输入或源码在准备期间变化时停止完成版本；无完整清单的目录不能被激活。已经完成的版本不能再次完成或覆盖。

## 切换与回退

激活前核验候选版本及当前发布记录。通过操作系统文件锁串行处理切换，并核对调用者读取的发布编号；如果其他发布方先切换了当前版本，本次操作会报冲突，不静默覆盖。

发布历史和临时指针先写入并刷新到磁盘，然后通过一次 `os.replace` 替换 `current.json`。读取方读取一次当前指针，再使用其指定的不可变版本；失败或未完成的候选不会混入当前报告。中断前留下的临时指针或历史记录不作为当前状态。

回退使用同一个激活接口，选择仍通过完整性校验的旧版本。旧报告和历史记录全部保留。本机制提供报告版本的原子可见性，不代表 API、BI、数仓和 CDC 的整套数据已经支持联合原子切换；也不以本次验收宣称断电恢复或生产高可用已完成。

## 查看与命令

- [本次归档报告](../output/extensions/report_delivery_59739398ee7f/store/versions/report_a6f2737522ca4516/report.html)
- [可阅读的验收记录](../output/extensions/report_delivery_59739398ee7f/verification.md)

准备新版本及核验当前状态：

```powershell
python -m tools.report_delivery build
python -m tools.report_delivery current
```

`build` 输出版本标识后，核验及激活所选版本：

```powershell
python -m tools.report_delivery verify report_这里填实际版本标识
python -m tools.report_delivery activate report_这里填实际版本标识
```

回退时将 `activate` 的参数改为旧版本标识。自动发布调用者应使用 Python 接口的 `expected_publication` 参数传入先前读取的发布编号。

读取本次隔离验收目录的当前版本：

```powershell
python -m tools.report_delivery --root D:\industrial_energy_analysis\output\extensions\report_delivery_59739398ee7f\store current
```

重放本次归档数据并保存到新文件：

```powershell
python -m tools.report_delivery --root D:\industrial_energy_analysis\output\extensions\report_delivery_59739398ee7f\store replay report_a6f2737522ca4516 --output D:\industrial_energy_analysis\tmp\report_replay_20261008.html
```

重放要求当前源码摘要与归档记录一致，并验证生成的 HTML 与归档文件逐字节一致。源码不匹配时拒绝重放，已归档的自包含 HTML 仍可直接使用。重放只能写到版本目录之外的新文件，不能覆盖已有产物；输入 JSON 保留原始字段顺序，避免字段重排导致 HTML 字节漂移。版本保存了源码摘要，尚未打包独立的 Python 运行环境或全部历史源码。
