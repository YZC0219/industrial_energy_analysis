# 智能诊断工作台

启动：在项目根目录执行 `python -m uvicorn src.api:app --host 127.0.0.1 --port 8010`，访问 <http://127.0.0.1:8010/diagnostics>。

工作台读取当前 `ENERGY_OUTPUT_DIR`（默认项目 `output`）中的 Q03、Q16、Q22、Q28。筛选车间、日期和处理状态，选择异常后查看原始证据、同期能耗与产量、核查建议及处理历史。月度告警按月首日筛选；车间均值是原 Q16 检测基线，不是次日预测。

问答围绕所选异常的车间和日期检索证据。服务进程配置 `LLM_API_URL` 和 `LLM_MODEL` 后调用已有模型适配器，鉴权通过 `LLM_API_KEY`；模型只能选择本次检索证据，不能生成未被证据支持的结论。未配置模型时界面明确显示证据检索模式，此模式只摘录匹配记录，不能理解复杂问答。直接运行 uvicorn 不自动加载 `.env`，可使用下面的启动器加载。原因类问题继续拒绝未经证实的设备根因。

## 本地模型配置与启动（2026-10-05）

在 `D:\industrial_energy_analysis\.env` 中填写 `LLM_API_URL`（完整 Chat Completions 地址）、`LLM_MODEL` 和 `LLM_API_KEY`。密钥仅保存在本地，不填写到页面或聊天中。

执行 `python -m tools.start_diagnostics --mode online` 加载配置并启动；地址仍为 <http://127.0.0.1:8010/diagnostics>。在线必需字段缺失或地址/超时无效时启动器明确报错。进程已有非空环境变量优先于文件，启动器只加载问答及工作台存储相关字段，不加载其他数据库凭据。依赖已声明在 requirements.txt。

`--mode offline` 强制使用离线规则；默认 `--mode auto` 根据有效配置选择模式。页面显示配置状态，`GET /api/v1/diagnostics-model` 只检查配置，不发起模型调用、不返回地址或密钥。已配置不等于连接及质量已验收，须实际运行在线评测后判断。

本项目当前选择 DeepSeek。按 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)核对，使用 `LLM_API_URL=https://api.deepseek.com/chat/completions`、`LLM_MODEL=deepseek-flash`。非敏感默认值已填入本地 `.env`；现有非空配置不会被覆盖。DeepSeek 密钥为空时，自动模式继续提供离线诊断，页面提示待填写密钥，在线启动则拒绝缺少密钥的配置。

2026-10-05 已完成工作台在线验收，记录在 `output/diagnostics/online_acceptance_20261005.json`：4/4 场景通过，其中异常证据、同期费用、缺少检修记录三项实际调用模型，未经确认的故障原因由本地守卫拒答。修复月度候选证据被其他检测记录挤出的检索问题，工作台仅提供当前事件、车间映射和同期日记录，并保留全部月度记录供选择。该验收是四个场景的小规模检查，不代表所有自然语言问答均已验证。

反馈状态包括待核查、已确认异常、误报、已处理。确认、误报和已处理必须填写判断依据，已处理还需填写措施。处理人由用户填写，当前本地服务未认证身份。记录只追加，保存完整历史；反馈是人工记录，不自动成为经过验证的训练标签，也不自动证明节能收益。

存储默认位于 `D:\industrial_energy_analysis\output\diagnostics`：`feedback.sqlite3` 保存反馈，`audit` 保存逐次问答证据和结果。可通过 `ENERGY_DIAGNOSTICS_DB` 和 `ENERGY_DIAGNOSTICS_AUDIT_DIR` 改到另一个 D 盘目录。分析批次更新后，同一车间、日期和检测类型的异常保留反馈；不再出现的异常不在当前列表展示，历史仍保存在数据库。反馈不修改 MySQL、Hive、CSV 或原有调度任务。

本次交付是智能诊断入口和处置反馈闭环。日度预测服务化、设备数据接入和节能实测仍需后续实施。

## 2026-10-04 优化

- 状态统计随车间、日期和优先级条件变化；统计不受单一状态筛选影响，点击统计卡可切换状态。
- 支持仅优先核查及未处理优先排序。优先级仍为检测规则，不代表故障概率。
- 详情展示单耗偏高/偏低、相对均值偏差，以及日度事件当日及之前 13 天、月度事件所在月的综合能耗趋势。趋势使用已有日记录，不补造缺失点。
- 未连接在线模型时，异常证据问题直接选择当前事件记录，费用、产量和碳排问题选择同期 Q28 日记录。未知问题和未经证实的原因继续返回证据不足，车间总览不作为当前异常的回答。
- 费用等合计只汇总回答引用的日记录，并显示引用天数；不把部分日期合计写成完整月份结果。在线服务也按实际引用记录计算。
- 刷新及分页使用已提交的筛选条件，切换筛选清空旧详情，快速切换异常时忽略过期响应。界面时间明确使用北京时间。
- 页面提交当前反馈版本；若另一人已追加反馈则返回 409，保留原输入，提示刷新核对后重提。旧接口调用未传版本仍兼容，但不具备此并发检查。

浏览器验收工具 `tools/verify_diagnostics_browser.py` 会写入测试反馈，必须针对配置了独立反馈数据库的本地服务运行。
