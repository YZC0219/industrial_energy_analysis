# 项目学习与复现入口

目标：完整掌握当前项目并可独立复现。当前材料与助手运行证据不能替代用户掌握；学习课次仍停在第一课，等待练习反馈。第16课等高级材料属于提前准备，不代表课程已完成。

## 推荐学习顺序
1. 回到第一课：解释业务问题、总量与单耗、模拟与真实、记录粒度。
2. 阅读原始字段与清洗规则，实际运行生成/清洗，并解释留痕。
3. 理解表粒度、关联和SQL口径，再练习独立入库、查询与结果核对。
4. 追踪报告和接口到查询文件，理解筛选与快照更新。
5. 按原21课继续调度、分层数仓、预测、归因、实时、治理与真实案例。
