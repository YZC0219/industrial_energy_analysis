# 前端分析公式独立扩展

本窗口已只读核对相关会话分工：CDC 窗口正在处理主业务批次与数仓对账；bug 窗口正在处理输入、预测和守护进程。这里限定为三类前端分析公式，避免修改共享主流程。

实现分为独立 YAML 契约、Python 参考计算、浏览器解释器和单独报告生成器。现有模板、报告生成器、语义目录、主 DAG、README 与整体汇总均保持只读。生成器只在新 HTML 内接入公式，检查每段集成锚点仅出现一次，并检查源码和语义导出记录在生成期间未变化；不匹配时退出，防止误套新模板或并发修改导致混合版本。

| 公式 | 统一规则 | 修正或明确的边界 |
| --- | --- | --- |
| 月环比 | 相邻日历月：本月 / 上月 − 1，结果乘 100 | 缺月、首月、上月为零时为空；筛选到部分月份只比较选中天数，并注明 |
| 七日移动平均 | 当前日及之前六个日历日内，筛选后有数据日期的均值 | 不是最近七条观测；仅选周末时不会把七个周末当作七天，不将缺日补零 |
| 费用帕累托 | 能源费用降序，分项费用 / 同范围总费用，累计占比首次达到 80% | 同费用保持输入顺序；总费用为零时占比为零且无阈值点 |

例如周末记录为 1 月 4 日 2、5 日 4、11 日 20、12 日 40，七日历日均值依次是 **2、3、12、30**。1 月 12 日的窗口只纳入 11、12 日；旧的按观测条数算法会把前一个周末也计入。

报告保留其原有视图、筛选与重置操作。只替换上述三类公式，未重新定义工业基线、风险归因或节能情景。独立报告使用系统字体，不依赖 Google Fonts；测试使用现有 Chrome，其专用用户目录也在 D 盘。

## 复现

在项目根目录运行：

```powershell
python -m tools.build_analysis_report
python -m tools.verify_analysis_report
python -m pytest tests/test_analysis_formulas.py -q --basetemp D:/industrial_energy_analysis/tmp/analysis_formula_tests
```

生成器读取最新成功的本机语义导出目录，不查询或写入数据库，不触发主数仓批次。输出保存在 D 盘项目 `output/extensions/analysis_formulas_<批次>/`，含报告 HTML、源码/契约清单、浏览器验收记录及截图。每次创建新目录，不覆盖现有报告。

## 验收范围

- 15 项独立测试通过：跨年相邻月、缺月、零分母、周末日历窗口、稳定排序、80% 临界点、零费用、非法日期、重复/倒序日期、非有限/负数/布尔计量值、溢出和模板漂移。
- 浏览器与 Python 在全量、连续三个月、W04 部分月、周末、空日期区间五种范围下逐项核对。
- 实际页面日期筛选、月度表、周末筛选、移动平均图的末值、帕累托图及重置操作通过，浏览器无脚本错误。
- 源码摘要在生成与浏览器核验结束时一致；其他窗口的主流程和运行记录未改写，也没有重复运行其数仓验收或全库 bug 回归。

当前属于可独立生成和使用的报告扩展，尚未把原 Airflow 报告节点切换到该生成器。这样保留其他窗口正在维护的主流程；直接打开本次独立报告即可查看新公式。

后续接入更新：三类公式现已进入正式报告渲染入口，独立生成工具继续复用同一入口；原报告命令与 `build_report` 操作器已单独验收，见[入口接入说明](分析公式接入原报告入口.md)。上段描述保留为独立扩展阶段的历史边界；已部署的 CDC 项目副本仍未替换。
