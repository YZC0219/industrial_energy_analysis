# 两个月项目学习计划（60个学习日）

目标：完整理解并能独立复现当前项目。按约两个月、60个学习日推进；日期不是掌握证明。不要求第一天全懂。遇到不理解先复习，可以顺延，不为赶进度跳过问题。

## 学习节奏
每天建议20～40分钟；实操复杂时可拆成两次。一次只讲当天主题，先回顾，再给图解、详细讲解卡片、实际文件、一个例子、小练习与参考答案。每周留复习和排错日。前期不需要掌握SQL、Docker或模型。

用户亲自解释、操作和核对结果，才记录为掌握。助手已跑通的实验仅作为后续教材和参考证据，不计入用户完成课次。未收到反馈时标记“已讲解，掌握待确认”。

## 第一天到什么程度就够
能说出项目主要用途，理解“用电增加不一定意味着每吨更耗电”，知道主线使用模拟数据。今天不要求理解建库、增量、模型或CDC。

```mermaid
flowchart LR
 A[第1—14天：业务和数据] --> B[第15—28天：指标与数据库]
 B --> C[第29—42天：报告、接口和工程流程]
 C --> D[第43—56天：预测、实时和真实案例]
 D --> E[第57—60天及补练：独立复现与验收]
```

第一天例子：昨天1000度/100吨=10度/吨；今天1200度/150吨=8度/吨。总用电增加，但单位产品用电减少；还需检查产品和生产条件是否可比。

第一天练习：用一句话描述项目用途。参考：把能源与产量记录整理成指标和图表，帮助工厂发现值得核查的用能问题。
