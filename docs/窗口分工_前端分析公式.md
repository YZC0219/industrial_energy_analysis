# 本窗口工作范围

2026-10-04 已只读检查同项目的本机会话记录：

- 职业扩展窗口：CDC 主业务每日批次、数仓对账及交付清单。
- Bug 修复窗口：输入约束、预测特征、滚动验证、流批对账、深度模型及守护进程边界。
- 本窗口：月环比、七日移动平均、费用帕累托的统一分析契约和独立报告生成/浏览器核验。

本窗口新增文件限定为 `governance/analysis_formulas.yaml`、`governance/analysis_formulas.py`、`src/analysis_formulas.js`、`tools/build_analysis_report.py`、`tools/verify_analysis_report.py`、`tests/test_analysis_formulas.py` 及对应说明。既有 `src/report_template.html`、`src/make_report.py`、`governance/catalog.py`、主 DAG、CDC/预测/告警源码、README 和全局运行汇总保持只读。

公式在独立生成的 HTML 中应用，输出位于 D 盘项目 `output/extensions/analysis_formulas_<批次>/`。不覆盖既有报告，不启动数仓更新，不替代其他窗口的 bug 审查。生成器检查替换锚点与源文件摘要，遇到并发编辑或不支持的模板结构即退出，防止生成混合版本。

阶段一：三类公式独立扩展完成，15 项测试及真实浏览器核验通过，历史验收目录为 `analysis_formulas_90b3d3a2e2c6`。

阶段二：后续用户要求继续，已检查其他窗口当前正在整理 bug/CDC 验收材料。本窗口将公式集成移入 `governance/analysis_report.py`，并在本窗口维护的 `src/make_report.py` 接入；新增可选输入/输出路径及 `tools/verify_report_entry.py`。只验证报告节点，不触发主数仓批次，不替换现有 CDC 部署。23 项相关测试通过；正式 CLI 与 Airflow 报告操作器的输出一致。具体边界见[入口接入说明](分析公式接入原报告入口.md)。
