# 三类分析公式接入原报告入口

2026-10-04 已将三类分析公式接入 `src/make_report.py` 的正式渲染路径。原有 Airflow `build_report` 命令仍为 `python src/make_report.py`，新生成的报告自动包含月环比、七日历日均值与费用帕累托，无需另外调用独立扩展生成器。

公式集成逻辑从预览工具移到应用模块 `governance/analysis_report.py`。预览工具继续使用同一个正式渲染入口，避免两份公式或两套报告渲染流程。保留模板锚点检查：模板结构不兼容时停止生成，不能静默退回旧公式。

## 生成方式

已有命令继续可用，写入项目默认报告：

```powershell
python src/make_report.py
```

需要读取某个已确认的分析快照、并单独保存新报告时，可指定路径：

```powershell
python src/make_report.py --input-dir D:\industrial_energy_analysis\output --output D:\industrial_energy_analysis\output\extensions\report_review\report.html
```

输入目录需包含完整的 Q01～Q29 分析产物。模板或输入校验失败时，不覆盖原已生成的目标报告；输出父目录在校验完成后创建。公式规则及筛选边界见[独立扩展说明](前端分析公式独立扩展.md)。
