2026-10-03，报告生成器开始把 YAML 中的七个基础指标编译成浏览器契约，并在生成 HTML 时内嵌独立的指标计算器。HTML 保持自包含，离线打开即可筛选，不需要 API 服务。每份契约记录指标定义、字段映射、单位、汇总规则、公用工程排除规则、单车间限制，以及 Q28 SQL 摘要和契约摘要。

本次修正了三项既有问题：

- 能源和车间费用占比的分母原先误用能耗总量，现改为对应费用总量。
- 大屏单耗原先额外排除非生产日，与注册表/API 不一致，现按注册表对选中车间日求和；停产标志不等于零产量，不能自动丢弃这些记录。
- 原单位统一写 `kgce/t`，现明确显示 `kgce/产量单位`，避免把件、台、平方米等误标为吨。

净用能占比也随当前筛选重新计算；选中非公用工程的单车间后显示 100%，不再沿用全厂的静态占比。空集指标值为 null，页面总量兼容显示为零；多生产车间的单耗不提供合并值，零分母也不提供单耗。公用工程不参与单耗计算。
