# 能迹任务定位

目标是把用户的话映射到实际入口、调用链和可验证的结果。此技能不提高预测或归因模型的统计命中率。

## 定位

- 从当前工作目录确认项目根目录；默认项目为 `D:\industrial_energy_analysis`。下文代码路径均相对项目根目录，工作树路径变化时使用实际根目录。
- 先提取用户要改变的可观察行为、涉及的页面/接口/指标和验收条件。已有具体目标时直接行动；只在歧义会改变实现时询问，并继续可独立完成的定位。
- 需要模块定位时，读 [入口地图](references/entry-map.md) 中相关行，然后用 `rg -n` 在对应模块搜索页面文字、字段名、路由或报错。没有命中时先用 `rg --files` 找文件，再扩大到源码和文档。
- 不默认遍历 `output/`、`data/`、`tmp/`、依赖目录和密钥文件；只有需要核对某份输入或证据时读取指定产物。
- 地图是候选入口，不是实现证据。实际读入口及其直接调用方，记录“用户看到的行为 → 入口 → 计算/状态来源”；确认后停止重复扫描。
- 改动前查看 `git status --short`，保留其他窗口的已有修改。区分当前源码、生成报告和部署目录中的冻结源码副本。

## 交接与实施

用简短说明给出已确认的入口、拟改范围和验收结果，再完成用户已授权的修改。只有定位请求时不擅自改变业务行为。
需要指标/报告修改、运行排障或选择验证时，可按当前问题读取同目录下的相应项目技能；不必加载所有技能。

新产物和缓存使用 D 盘。结束时报告具体改动和证据；没有做定位命中率的前后对照，就不声称提升百分比。
